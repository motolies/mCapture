# mCapture 설치 안내

mCapture는 메뉴바에 상주하는 스크린샷 캡처·주석 앱입니다.
Apple 공증을 받지 않은 앱이라 처음 한 번은 아래 절차로 직접 허용해야 합니다.


## 요구 사항

- Apple Silicon(M 시리즈) Mac. Intel Mac에서는 실행되지 않습니다.
- macOS 15 이상


## 1. 설치

1. 이 창의 mCapture를 옆의 Applications 폴더로 끌어다 놓습니다.
2. 설치가 끝나면 Finder 사이드바에서 mCapture 디스크를 꺼냅니다(⏏).

다운로드 폴더나 이 디스크 안에서 바로 실행하지 마세요.
macOS가 임시 위치에서 실행해 "로그인 시 실행" 같은 설정이 제대로 동작하지 않습니다.


## 2. 처음 실행 허용

응용 프로그램 폴더에서 mCapture를 열면
"Apple이 악성 코드가 없음을 확인할 수 없다"는 경고가 뜹니다.

1. 경고 창에서 [완료]를 누릅니다. [휴지통으로 이동]은 누르지 마세요.
2. 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
3. 아래쪽 보안 항목에서 mCapture가 차단되었다는 문구 옆의 [그래도 열기]를 누르고 암호를 입력합니다.
4. 다시 뜨는 확인 창에서 [그래도 열기]를 누릅니다.

[그래도 열기] 버튼은 실행을 시도한 뒤 약 1시간 동안만 보입니다.
보이지 않으면 mCapture를 한 번 더 열어 본 뒤 다시 확인하세요.

터미널을 쓸 수 있다면 아래 명령 한 줄로 1~4를 대신할 수 있습니다.

    xattr -dr com.apple.quarantine /Applications/mCapture.app


## 3. 화면 기록 권한 허용

mCapture는 창이 없는 메뉴바 앱입니다.
실행되면 Dock이 아니라 화면 위쪽 메뉴바에 카메라 모양 아이콘만 나타납니다.

1. ⌃⇧4(Control+Shift+4)를 누르면 화면 기록 권한 요청이 뜹니다. [시스템 설정 열기]를 누릅니다.
2. 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 mCapture를 켭니다.
3. 메뉴바 아이콘 → mCapture 종료를 누른 뒤 mCapture를 다시 실행합니다.
   권한은 앱을 다시 실행해야 적용됩니다.

macOS가 가끔 화면 기록을 계속 허용할지 물어볼 수 있습니다. 허용을 유지하면 됩니다.


## 4. 사용법

- 영역 캡처: ⌃⇧4 → 드래그로 영역 선택 (Esc로 취소)
- 전체 화면 캡처: ⌃⇧1
- 캡처하면 클립보드 복사, 파일 저장(~/Pictures/mCapture), 에디터 열기가 함께 일어납니다.
- 단축키, 저장 폴더, 캡처 후 동작은 메뉴바 아이콘 → 설정…(⌘,)에서 바꿀 수 있습니다.
- 설정의 "로그인 시 실행"을 켜면 Mac을 켤 때 자동으로 시작합니다.


## 5. 업데이트

1. 메뉴바 아이콘 → mCapture 종료
2. 새 DMG의 mCapture를 Applications 폴더로 끌어다 놓고 [대치]를 누릅니다.
3. 처음 실행할 때 "2. 처음 실행 허용"을 다시 거쳐야 할 수 있습니다.

화면 기록 권한은 보통 그대로 유지됩니다.
업데이트 후 캡처가 되지 않으면 아래 문제 해결을 보세요.


## 6. 문제 해결

"손상되었기 때문에 열 수 없습니다"가 뜰 때
: 터미널에서 아래 명령을 실행한 뒤 다시 엽니다.

    xattr -cr /Applications/mCapture.app

권한을 허용했는데도 캡처되지 않거나 권한 요청이 반복될 때
: 화면 및 시스템 오디오 녹음 목록에서 mCapture를 선택해 [−]로 지운 뒤,
  mCapture를 다시 실행해 권한을 새로 허용합니다.

메뉴바 아이콘이 보이지 않을 때
: 노치가 있는 MacBook은 메뉴바 아이콘이 많으면 노치 뒤로 숨깁니다.
  단축키는 그대로 동작하며, 설정은 터미널에서 아래 명령으로 열 수 있습니다.

    open mcapture://settings

"단축키 등록 실패" 알림이 뜰 때
: 다른 앱이 같은 단축키를 쓰고 있습니다. 설정에서 단축키를 바꾸세요.


## 7. 제거

1. 설정에서 "로그인 시 실행"을 끕니다.
2. mCapture를 종료하고 Applications 폴더에서 휴지통으로 옮깁니다.
3. 설정과 권한 기록까지 지우려면 터미널에서 실행합니다. (선택)

       defaults delete com.motolies.mcapture
       tccutil reset ScreenCapture com.motolies.mcapture

캡처한 이미지는 저장 폴더(기본 ~/Pictures/mCapture)에 그대로 남습니다.
